# 🦘 BoboCalo — 矮袋鼠與 Bobo 的溫柔療癒熱量紀錄 × 運動跟練平台

暖奶茶手繪塗鴉風的個人飲食熱量、咕嚕喝水打卡與居家靜音運動動畫計時 Web App（支援 iPhone Safari「加入主畫面」全螢幕體驗與跨瀏覽器前端加密同步）。

## ✨ 核心功能

1. **📸 拍照／文字 AI 算卡路里 ＋ 台灣常見美食離線字典**
   - 手機直接拍下餐點照片或輸入描述（如「雞腿便當飯吃一半＋無糖綠茶」），透過個人 Gemini API Key 拆解菜色份量、熱量與三大營養素，並獻上矮袋鼠與 Bobo 的**溫柔療癒誇誇風**鼓勵！
   - 內建台灣早餐店、便當小吃、超商輕食、手搖飲速查庫，免網路也能快速微調。
2. **🔥 三合一運動挑戰搭配**
   - **每日熱量預算儀表板**：依個人身高、體重與目標自動計算 BMR / TDEE 與安心剩餘額度。
   - **餐後智慧組合菜單**：一鍵切換「🌱 輕鬆消食 25%」、「🌤️ 活力半糖 50%」、「🔥 100% 全消挑戰」。
   - **自由湊單＆動作圖鑑**：依個人體重即時換算運動消耗卡路里，自由加入湊單籃。
3. **🎬 矮袋鼠 ＆ Bobo 動態姿勢教學 ＋ 倒數計時器**
   - 內建 **11 款居家靜音不傷膝＆餐後消食瑜珈動作**（含 **180 BPM 原地超慢跑專屬節拍器音效**、慢速靜音深蹲、躺姿臀橋、棒式、死蟲式、貓牛式、下犬式等）。
   - 支援 `3-2-1` 準備倒數、換邊提醒音、組間休息計時與烤棉花糖努力印章 🍡。
4. **💧 Bobo 咕嚕喝水小站**
   - 動態水位漂浮 Bobo，一鍵記錄 `+150ml / +250ml / +350ml / +500ml`。
5. **🔐 零個資公開、跨 Safari ↔ iPhone「加入主畫面」前端加密同步**
   - 公開程式碼不含任何個人密碼或 API Key。輸入自訂通行碼即以 `PBKDF2 + AES-GCM` 前端加密同步飲食、喝水與 API Key。
